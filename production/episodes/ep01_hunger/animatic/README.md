# Episode 1 — Animatic

The animatic is the single highest-leverage step in the production pipeline. It plays the entire episode in rough form — storyboards + scratch VO + temp music — before any final keyframes or video clips are rendered.

If the animatic plays, the episode plays.
If the animatic doesn't play, no amount of beautiful watercolor will save us.

## Build pipeline

```
descriptor.json   ← timing + VO + board ref per shot (source of truth)
       │
       ├── boards/<shot>.png      ← rough Z Image boards (Higgsfield, ~7 credits total)
       ├── audio/<voice>_<NN>.mp3 ← scratch VO (ElevenLabs V3, ~$5-10)
       │
       └── assemble.sh            ← FFmpeg builds the MP4
              │
              └── ep01_animatic_v1.mp4   ← what you watch
```

## What's in this folder

- **descriptor.json** — every shot's timing, narration, dialogue, and character list. Edit shot durations here to re-time the cut. Source of truth.
- **boards/** — rough Z Image gens, one per shot. PNG. Each board is referenced by `<shot>.png`. Generated by `build_boards.py` (next pass).
- **audio/** — scratch VO clips. Naming: `<character>_<NN>.mp3` (e.g. `anima_01.mp3`, `leena_03.mp3`). Generated by `build_vo.py` (next pass).
- **scratch/** — temp working files (intermediate FFmpeg outputs). Gitignored.
- **assemble.sh** — runs FFmpeg to combine boards + audio + transitions into the final MP4. Next pass.
- **ep01_animatic_v1.mp4** — the watchable animatic. Output of `assemble.sh`. Gitignored.

## Three-phase build

### Phase 1 — scratch VO (ElevenLabs)
Render every narration line + dialogue line per the descriptor. Uses the existing V3 cast in [scripts/generate_vo.py](../../../../scripts/generate_vo.py) plus a new Morrow voice (placeholder until producer-approved Voice Design lands).

**Cost:** ~$5–10 in ElevenLabs API budget. Negligible vs the Higgsfield video stage.

### Phase 2 — rough boards (Higgsfield Z Image)
One Z Image gen per shot. For character shots: pass character reference image from `refs/<character>/` as `medias[].role=image`. For environment shots: pass the style anchor (when it exists) or a curated watercolor reference.

**Cost:** ~48 shots × 0.15 credits = **~7 credits, roughly $0.20** at basic plan rates.

### Phase 3 — assembly (FFmpeg)
Concatenate boards as 24fps stills held for each shot's duration, layered with the appropriate audio tracks. Add 0.5s fades between shots. Output a single MP4.

**Cost:** zero. FFmpeg runs locally.

## Open before phase 1

- **The style anchor PNG.** Still missing. For animatic-quality boards, anchor isn't strictly required (boards are rough by definition). We can re-board against the locked anchor for v2 if needed.
- **Morrow's voice.** Will be a single ElevenLabs V3 line at scratch quality; final Voice Design lands when we hit Episode 3 production proper.
- **Music.** None at v1. Sound design pass comes later. Silence under board cuts is fine for the animatic gate.

## Acceptance criteria

The animatic is approved when **the producer watches it end to end and feels the episode's heart land**. Specifically:

1. The twelve-second hold (shot 24) does not feel slow.
2. The "Cut the channel" / "Don't" exchange (shots 37–38) lands without explanation.
3. Mira's single line (shot 45) breaks the audience for the rest of the episode.
4. The cursor blinks at the end (shot 47) feel inevitable, not pretentious.

If any of those four fail, we revise the script or shotlist — _not_ the boards or audio.
